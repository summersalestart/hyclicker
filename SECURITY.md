# Security Policy

## Reporting a Security Vulnerability

If you believe you have found a security vulnerability in Novum please report it privately rather than opening a public GitHub issue.

When reporting a vulnerability please include:

* A clear description of the issue
* The version of Novum affected
* Steps to reproduce the issue
* Any relevant screenshots, logs, or information
* Your suggested fix, if you have one

Please allow reasonable time for the issue to be investigated before publicly disclosing it.

## Supported Versions

Security fixes are generally provided for the latest release of NOVUM.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Download Security

Official Novum releases are published through the GitHub Releases page:

https://github.com/FakePancak3/novum/releases

The Windows executable is currently unsigned so Windows may display a Microsoft Defender SmartScreen warning.

For additional verification compare the SHA-256 checksum of the downloaded executable with the checksum published alongside the corresponding release.

If the checksum does not match do not run the executable.

## Scope

Security reports should concern vulnerabilities in Novum itself, its source code, or its official release/build process.

Issues caused by third-party software, modified copies of NOVUM, or unofficial distributions may be outside the project's scope.
